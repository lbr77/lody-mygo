Not in scope: the iOS simulator stream (`SimulatorStream`), which this desktop client leaves out by choice. E2EE workspaces: neither lody-ios nor Lody's web client opens encrypted content (Lody's `@lody/e2ee-core` README: production E2EE composition is not enabled and no browser or native implementation is); Lody Native, like them, asks `e2eeWorkspaces:describe` and holds an encrypted workspace's content back with an explanation, except in local-only mode, where the machine's daemon serves it.
